Ejemplares físicos

Cada ejemplar físico tiene su propio número de inventario. Podés editarlo aquí y guardar el cambio; el sistema valida que no quede vacío ni repetido y actualiza la vista previa de códigos de barras. No cambia los identificadores de libros o ejemplares ni modifica préstamos existentes. El botón de preparación solo crea ejemplares faltantes.

Códigos de barras de ejemplares

El código de barras representa el número de inventario único de cada ejemplar físico. No hace falta agregar una columna ni modificar las tablas de Supabase: el sistema usa el inventario que ya identifica cada copia.

Para usar la cámara, abrí la biblioteca desde su dirección HTTPS (GitHub Pages) y autorizá el acceso a la cámara. La cámara del celular puede enfocar el código impreso en el libro o una etiqueta.

Etiquetas imprimibles en A4

Se crea una etiqueta por ejemplar. Usá papel autoadhesivo A4 o papel común y cinta adhesiva.

Los códigos se generan a partir de los números de inventario existentes. Antes de imprimir, revisá que cada ejemplar tenga un número único y legible.
